# Delivery Dashboard & Universal Plan Catalog

Каталог проектных планов, спецификаций и артефактов для создания машиночитаемого графа планов (`delivery-graph.json`) и интерактивного дашборда (`delivery_dashboard.html`).

## Артефакты в этом каталоге:

1. [**`plan.md`**](./plan.md) — Полная техническая спецификация, 4-уровневая иерархия планов, алгоритмы синтаксического анализа Markdown, логика сверки статусов и план верификации.
2. [**`mockup.html`**](./mockup.html) — Интерактивный HTML-мокап дашборда (Вариант Б) с реальными данными проектов `trade-robot-alpha` и `lift-fixed-price`.
3. [**`delivery-graph.schema.json`**](./delivery-graph.schema.json) — Каноническая JSON-схема стандарта `DeliveryGraph`.
4. [**`sample-delivery-graph.json`**](./sample-delivery-graph.json) — Пример сгенерированного графа планов, волн, задач и TODO-заметок для обоих проектов.

## Назначение подсистемы:
* Формирование актуального графа связей между стратегическими планами (`docs/plans/*.md`), исполнительными планами (`plan-sdlc`), запусками агентов (`.sdlc/execution/execute-*.json`) и отложенными задачами (`docs/TODO/*.md`).
* Предоставление визуального интерактивного дашборда для разработчиков и проектных команд с сохранением Markdown как первоисточника истины (SSOT).
